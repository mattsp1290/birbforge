Use an independent Claude review#

Inspect the installed CLI help and authentication status before the first call. In this planning session, the ordinary shell selected API-key authentication. A process-local invocation with the Anthropic API-key, auth-token and base-URL variables removed selected the existing Claude Max subscription. Safe mode disabled project customizations. This is observed session behavior, not a portable guarantee about every installation.

Give the reviewer the accepted scope, changed file paths, verification evidence and decision trail. Limit its tools to read-only inspection for this review. Do not forward private credentials or an entire notes hub. Use a fresh process for a fresh review. Confirm the returned model identity rather than treating an alias as evidence of the model used.

The owner evaluates findings, applies warranted fixes and reruns affected checks. Review must remain independent of authorship. When the approved review route is unavailable, report that missing gate and continue safe independent work. Do not substitute the author's own review for independent approval.
